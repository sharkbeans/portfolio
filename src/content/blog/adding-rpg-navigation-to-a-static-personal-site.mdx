This draft exists so the idea has a home before the full article does.

The finished version should document:

- Why the homepage itself is the level: headings, project blocks, and dividers become collision
  geometry read straight from `getBoundingClientRect()`, instead of a separate hand-drawn map.
- How document coordinates keep the player, the camera's edge-follow scrolling, and the cached
  collision rects aligned without fighting normal wheel and touch scrolling.
- What had to be done so the site still reads well with JavaScript disabled, with reduced motion
  enabled, or in the explicit reading-mode toggle.
- Where the sprite and interaction system can grow later without the game ever gating access to
  real content.
