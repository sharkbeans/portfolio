Site Editor

Edits content directly in sharkbeans/sharkbeans.github.io via the GitHub API: blog posts, standalone page write-ups (about, project case studies), the projects list, the uses page, your profile blurbs, and social links. You'll need a fine-grained personal access token scoped to only this repository, with Contents: Read and write permission and nothing else.

How to create one:

  1. Go to github.com → click your avatar (top right) → Settings → Developer settings (bottom of the left sidebar).
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Give it a name (e.g. "site editor"), and set an expiration — 30–90 days is plenty, don't use "No expiration."
  4. Under Repository access, choose Only select repositories and pick sharkbeans.github.io. Do not grant access to any other repo.
  5. Under Permissions, click Add permissions, type Contents into the search box, and check it. It'll appear in the permissions list below — set its dropdown to Read and write. Leave everything else as "No access."
  6. Click Generate token and copy it — GitHub only shows it once. Paste it below.
⚠️ This token grants write access to your site's source repo. It's stored unencrypted in this browser's local storage on this device and is sent only to api.github.com — never paste it into any other site. Don't use this on a shared or public computer. Click Disconnect when you're done editing to remove it from local storage, and let the token expire/revoke it from GitHub's settings if you no longer need it.
